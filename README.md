# @grodriguez-fr/agent-chat

Shared agent-chat UI and client primitives used by Talos, LOGOS and job-finder.

```tsx
import "@grodriguez-fr/agent-chat/styles.css";
import { AgentChatShell } from "@grodriguez-fr/agent-chat/react";

<AgentChatShell
  variant="page"
  brandName="Talos"
  controller={controller}
/>
```

## Exports

- `core`: normalized messages, tools, conversations and timeline helpers.
- `react`: page/panel shell, conversation navigation, timeline and composer.
- `client`: reconnecting WebSocket client and ACP/AI SDK protocol parsers.
- `styles.css`: framework-independent styles driven by `--agent-*` variables.

Application-specific behavior is supplied through an `AgentChatController` and
optional slots. Server APIs, persistence, permissions and product entities stay
inside each consumer.

## Talos appearance (0.2)

The shared timeline and composer use Talos as their visual reference: a 42rem
reading column, neutral user bubbles, borderless assistant answers, collapsible
execution/tool activity, and a rounded floating composer. Application themes
provide `--background`, `--card`, and `--muted`; `.dark` is supported.

- `fromLegacyMessages` adapts Talos and Job Finder stores without changing persistence.
- The default activity feed gives tools natural French labels, a compact card, and
  an optional technical detail view. `renderActivity` remains available for
  product-specific presentation.
- Markdown code blocks include copy and line-wrap controls in the shared package.
- Consecutive tool/reasoning updates fold into one flat activity group (ChatGPT
  style: one toggle per run of tools between texts, plain rows, inline detail).
  `renderActivity` remains available for product-specific presentation.
- `composerBefore`, `composerLeading`, and `composerTrailing` retain application controls.
- Sending during a turn requires `allowQueue: true`. A rejected send (`false` or
  a rejected promise) keeps the draft. Uploads can use `hasAttachments` and `sendingDisabled`.
- The composer hides dictation when unsupported and handles IME composition.

Job Finder, Talos and LOGOS currently pin the same
`vendor/agent-chat-0.2.3.tgz`, generated by `npm test && npm pack` here.
The archive is included in their build contexts and lockfiles, so builds do not
depend on an unpublished Git commit or a sibling checkout. For a new release,
bump the version, run tests, pack, and update all three archives and lockfiles
together. Source changes belong in this repository.
